## Build notes

- `main.ts` is a Node 22 program, standard library only (`node:fs`,
  `node:path`, `node:zlib`). No network, no packages, no randomness, no
  timestamps — two runs write byte-identical PNGs.
- The image is drawn, not copied: a 5×7 bitmap font, hand-built PNG
  encoder (zlib deflate level 9, CRC32), schematic world map with
  graticule and equator, 32 numbered region-coloured markers with leader
  lines to their true locations, and a two-column story list.
- The kit's RULES.txt states there is **no local grade** for this
  competition ("the server grades every entry"), so verification here is:
  two runs byte-identical, valid PNG (all chunk CRCs pass), 1024×1024,
  35,752 bytes (limit 1 MiB), plus visual inspection of the render.
- Nothing was submitted to make.fun; no account was created, no wallet
  connected, no money spent. Building only.
